重跑 Windows 隔离测试，脚本会在 `work/` 建一个临时 Vault、独立 Electron 配置与临时调试端口。

```powershell
npm ci
npm run typecheck
npm test
npm run build
node scripts/obsidian-smoke.mjs 'D:/obsidian/Obsidian.exe' "$env:APPDATA/obsidian/obsidian-1.15.0.asar"
```

最后一个参数可省略，使用 Obsidian 安装自带的应用包。测试所用 DSH 版本支持样例 Cordis 补丁。在实机验收前，将 [集成清单](INTEGRATIONS.md) 的路径指向隔离环境。

可选 FNS 测试使用单独运行在 `127.0.0.1` 的 FNS 3.6.1 服务和新建的测试同步 Vault。设置 `LIFEPILOT_FNS_PLUGIN_DIR` 为 FNS 插件产物目录。将 `LIFEPILOT_FNS_TEST_CONFIG` 指向测试配置 JSON，字段为 `api`、`apiToken`、`restToken`、`vault`。其中插件令牌授权 `ObsidianPlugin`、REST 与 WebSocket，REST 令牌是测试 WebGUI 会话令牌。脚本只复制插件程序文件，临时 Vault 使用上述测试凭据。
