## Ribbon 修复

- **根因**　Cupertino 3.2.12 将主 Ribbon 的侧栏开关布局绑定到 `.workspace-ribbon.mod-left`。Obsidian 1.15.0 的主 Ribbon 使用 `.workspace-ribbon.mod-primary`，侧栏开关的命中区域覆盖多数图标。隔离副本中，点击关系图谱坐标时，捕获到的实际点击目标是 `.sidebar-toggle-button`，随后侧栏收起，图谱没有打开。同样的坐标检测显示 FNS 自己的图标可以直接命中。
- **改动**　只修改目标 Vault 的 `.obsidian/themes/Cupertino/theme.css` 中这一条布局规则的选择器。新选择器为 `.workspace-ribbon:is(.mod-left,.mod-primary) > .sidebar-toggle-button`。原配置及主题已备份。
- **验证**　隔离副本加载相同主题和启用插件组合。切换默认主题时关系图谱恢复，加载修补后的 Cupertino 时也恢复。侧栏开关可独立收起与展开，FNS 菜单可打开。真实 Vault 的 FNS 无障碍状态显示「服务已连接」。Windows 拒绝了对该窗口的自动点击（0x80070005），真实窗口的点击尚需复核。
- **复核步骤**　重新加载或重启 Obsidian，依次点击关系图谱、侧栏开关和 FNS 菜单。若主题更新覆盖本地补丁，可先切到默认主题确认点击，再检查新版主题是否仍需这一条选择器修补。
